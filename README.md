# toybox

个人玩具盒 —— 想到什么就做点小东西。
*Small things, built for the fun of it.*

✨ 在维护 · 🧸 存档，不再维护

---

- ✨ **[`netease-recommend`](./netease-recommend/)** — 网易云音乐 AI 推荐歌单：读全库，顺着相似音乐人图谱挖你没听过的音乐人，每次 20 首换进同一个歌单并改名。零 npm 依赖。
- ✨ **[`hush`](./hush/)** — 浏览器扩展：让吵人的网站安静下来。网易云换 Apple Music 深色主题并藏掉多余 UI，X 在 9–21 点整页封锁，HN 深色大字，Codeforces 复古暖调。
- 🧸 **[`avatar_generator`](./avatar_generator/)** — 抽象头像生成器：递归矩形分割 + matplotlib 色图，Tkinter 实时预览。
- 🧸 **[`synthesizer`](./synthesizer/)** — FM 声音合成器：MATLAB 课程作业，振荡器与调制器可任意组合，突破 DX7 的 32 种固定算法。
